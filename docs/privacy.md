# Privacy

Effective date: November 27, 2026

**Cutout collects nothing about you.** There's no account, no analytics, no ads, and no tracking. Nothing you open, paste, or make is sent to us or to anyone else.

The app goes online for only two things: the images in a Figma copy you paste, and a daily check for a new version.

This page covers the Cutout app for Windows and Mac, the browser version at app.cutout.design, and the website at cutout.design.

## Your images

Cutout works on your computer. Images you open, paste, or drop in stay there. Every tool, Smart fill included, runs on your computer, and Cutout saves a file only where you choose.

## Figma copies

When you paste a normal Figma copy that contains images, the copy holds links to those images on Figma's servers. Cutout downloads the images from Figma to draw the paste, the same way Figma does. Nothing about you or your document is sent with that request, and no cookies are sent. Figma sees the request like any web request (your IP address and the time), under [Figma's privacy policy](https://www.figma.com/legal/privacy/).

## Update check

Once a day, when you open it, the desktop app asks GitHub whether a new version is out. The request carries nothing about you: no version number, no ID, and no cookies. Cutout compares the versions on your computer. GitHub sees the request like any web request (your IP address and the time). If there's a new version, Download opens the download page in your browser.

To turn this off, clear Check for Updates Automatically in the Cutout menu. To check right away, choose Check for Updates in the same menu. Versions from the Microsoft Store or the Mac App Store never check: the store updates them.

## Settings

Your settings (theme, tolerances, eraser size, window size, the last folder you saved to, and similar) are stored on your computer only. In the browser version, they're stored in your browser.

## Dragging a layer out

Dragging a layer out of Cutout writes a temporary PNG file for the drag. Cutout deletes it again, at the latest when you quit.

## The website and the browser version

cutout.design and app.cutout.design are hosted on GitHub Pages. GitHub logs visitors' IP addresses to run and secure the service, as described in [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). We don't see those logs.

The site uses no cookies and no analytics. If you switch between light and dark, the choice is kept only in your browser.

The browser version is a set of files your browser downloads from GitHub Pages. After that, it works like the desktop app: your images stay in your browser and are never uploaded.

## Downloads, donations, and stores

- **Downloads** come from GitHub Releases, under GitHub's privacy statement.
- **Donations**, if you choose to give one, go through GitHub Sponsors, with payments handled by Stripe, under their own policies. GitHub shows us your GitHub user name and sponsorship (a private sponsorship hides them only from others), and your email address only if you choose to share it.
- **Store versions**, if you get Cutout from the Microsoft Store or the Mac App Store, are covered by that store's terms and privacy policy for the download and any purchase. The app itself works the same way, except that the store handles updates.

Windows and macOS may send crash reports to Microsoft or Apple if you have that turned on in their settings. Cutout itself sends none.
